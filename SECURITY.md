# Security Policy

## Supported Versions

Only the latest version of INTELLIVORA available on the `main` branch is currently supported with security updates.

## Reporting a Vulnerability

If you discover a security vulnerability in INTELLIVORA, please report it privately instead of creating a public GitHub issue.

You can report security vulnerabilities through GitHub's private vulnerability reporting feature available in this repository's **Security** tab.

Please do not publicly disclose the vulnerability before it has been reviewed and addressed.

## What to Include

When reporting a security vulnerability, please provide:

- A clear description of the vulnerability.
- Steps to reproduce the issue.
- The affected feature, component, or file.
- The potential security impact.
- Relevant technical details or proof-of-concept, if available.

## Response

Security reports will be reviewed as soon as reasonably possible.

Depending on the severity and validity of the report, appropriate remediation may include fixing the affected code, updating dependencies, changing configuration, or releasing a security patch.

## Security Best Practices

Please do not include sensitive information in public GitHub issues, pull requests, or discussions, including:

- API keys
- Passwords
- Authentication tokens
- Private credentials
- Personal or confidential data

If sensitive information is accidentally exposed, report it privately so it can be handled appropriately.
