## Selected Projects

### OMNIX

**Multi-Agent AI Platform**

OMNIX is a modular AI platform that routes user requests across specialized agents and manages shared application state through a LangChain StateGraph architecture.

**Highlights**

- Orchestrates 8 specialized agents for chat, coding, web search, PDF processing, presentations, vision, and image analysis.
- Supports document-based questions through PDF text extraction and Qdrant vector search.
- Integrates Tavily web search and multiple LLM providers: Groq, Google Gemini, and OpenRouter.
- Uses MongoDB for persistence, Redis for sessions, Firebase Authentication, and credit-based usage management.
- Runs as a containerized multi-service application with Docker and Docker Compose.

**Stack:** React, Vite, Node.js, Express, MongoDB, Redis, LangChain, Qdrant, Docker, Groq, Gemini, OpenRouter, Tavily

### Zyven

**AI-Powered React Component Generation Platform**

Zyven helps developers create reusable React UI components from natural-language prompts. Generated JSX can be reviewed in a live browser preview and saved into a personal component library.

**Highlights**

- Generates React UI components through OpenRouter-powered AI workflows.
- Renders generated code in a live preview with `react-live`, including code cleanup and invalid-code safeguards.
- Provides user-controlled component saving, duplicate protection, and MongoDB-backed personal libraries.
- Implements Firebase Google Authentication, JWT-based protected routes, and httpOnly cookies.
- Uses credits and Razorpay payments with server-side signature verification.

**Stack:** React, Vite, Node.js, Express, MongoDB, OpenRouter, react-live, Firebase, JWT, Razorpay

### INTELLIVORA

**AI Interview Preparation Platform**

INTELLIVORA turns a candidate's resume and target role into a personalized AI interview practice experience, complete with evaluation, performance reports, and interview history.

**Highlights**

- Extracts and analyzes uploaded PDF resumes, including ATS-style and interview-readiness scoring.
- Generates interviews tailored to a candidate's role, experience level, and selected plan.
- Evaluates responses with structured AI feedback, scoring, and saved interview history.
- Implements Firebase Google Authentication, JWT authentication with httpOnly cookies, and MongoDB Atlas persistence.
- Includes credit-based workflows and Razorpay payments with server-side verification.

**Stack:** React, Vite, Tailwind CSS, Redux Toolkit, Node.js, Express, MongoDB Atlas, OpenRouter, JWT, Razorpay
