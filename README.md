## 🚀 Selected Projects

### OMNIX

**Multi-Agent AI Platform**

OMNIX is a modular AI platform that routes user requests across specialized agents and manages shared application state through a **LangChain StateGraph architecture**.

#### Highlights

- Orchestrates **8 specialized agents** for chat, coding, web search, PDF processing, presentations, vision, and image analysis.
- Supports document-based questions through **PDF text extraction and Qdrant vector search**.
- Integrates **Tavily web search** and multiple LLM providers including Groq, Google Gemini, and OpenRouter.
- Uses **MongoDB** for persistence and **Redis** for session management.
- Implements **Firebase Authentication** and credit-based usage management.
- Runs as a containerized multi-service application using **Docker and Docker Compose**.

**Stack:**  
React, Vite, Node.js, Express, MongoDB, Redis, LangChain, Qdrant, Docker, Groq, Gemini, OpenRouter, Tavily

### Zyven

**AI-Powered React Component Generation Platform**

Zyven helps developers create reusable React UI components from natural-language prompts. Generated JSX can be reviewed through a live browser preview and saved into a personal component library.

#### Highlights

- Generates React UI components through **OpenRouter-powered AI workflows**.
- Renders generated code in a live preview using `react-live`.
- Includes code cleanup and safeguards against invalid generated code.
- Provides user-controlled component saving and duplicate protection.
- Uses **MongoDB** for personal component libraries.
- Implements **Firebase Google Authentication** and JWT-based protected routes.
- Uses **httpOnly cookies** for authentication.
- Includes credit-based workflows and **Razorpay payments** with server-side signature verification.

**Stack:**  
React, Vite, Node.js, Express, MongoDB, OpenRouter, react-live, Firebase, JWT, Razorpay

### INTELLIVORA

**AI Interview Preparation Platform**

INTELLIVORA transforms a candidate's resume and target role into a personalized AI interview preparation experience with interview evaluation, performance reports, and interview history.

#### Highlights

- Extracts and analyzes uploaded **PDF resumes**.
- Provides ATS-style and interview-readiness scoring.
- Generates interviews based on the candidate's **role, experience level, and selected plan**.
- Evaluates candidate responses with structured AI feedback and scoring.
- Stores interview results and history using **MongoDB Atlas**.
- Implements **Firebase Google Authentication**.
- Uses JWT authentication with **httpOnly cookies**.
- Includes credit-based workflows and **Razorpay payments** with server-side verification.
- Includes an **Aptitude Preparation System** with topic selection, tests, progress tracking, attempts, and results.

**Stack:**  
React, Vite, Tailwind CSS, Redux Toolkit, Node.js, Express, MongoDB Atlas, OpenRouter, JWT, Razorpay
